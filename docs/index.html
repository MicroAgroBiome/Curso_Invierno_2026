Objetivo

Desarrollar habilidades para identificar y cuantificar diferencias estadísticas y topológicas entre comunidades microbianas usando herramientas de análisis de datos y topología aplicada.

Resultados

Al finalizar, cada estudiante presentará un análisis comparativo de comunidades microbianas y su interpretación biológica (ver Proyecto del curso).

Estructura académica

Se combinarán herramientas de estadística multivariada, análisis topológico de datos (TDA) e inferencia ecológica para caracterizar la diversidad microbiana. Los participantes trabajarán con conjuntos de datos reales de comunidades microbianas, aplicando métodos comparativos que integran estadística clásica y geometría de datos.

Objeto de estudio

Analizamos comunidades microbianas de la rizósfera de cultivos (el suelo que rodea las raíces) a partir de metagenomas reales, y comparamos su estructura estadística y topológica para identificar patrones de diversidad y organización. Se enfatiza el uso de:

  • Análisis de diversidad microbiana
  • Comparación estadística entre comunidades
  • Métodos de topología aplicada a datos biológicos
